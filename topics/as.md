# TCP Facts 2026-10-14: as

- Auto Scaling (AS) is a service that automatically scales Elastic Cloud Server instances and bandwidth out and in by conditions the customer sets. Scaling is triggered by alarm-based policies on Cloud Eye metrics such as vCPU, memory, disk or inbound traffic, by scheduled policies or by periodic policies, and AS works together with Elastic Load Balancer, Elastic Volume Service and Elastic IP. The Regions and Endpoints page lists API endpoints for AS in eu-de and eu-nl. (KB-4COH, contract, checked 2026-10-14)
