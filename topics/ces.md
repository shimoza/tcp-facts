The call answers 201 without a body, while each data point is deleted once its ttl expires. (KB-FEHS, docs, checked 2026-09-25)

The Regions and Endpoints page lists API endpoints for Cloud Eye in eu-de and eu-nl. (KB-FK5P, contract, checked 2026-10-14)
