# TCP Facts 2026-11-23: windows

- Microsoft: with Djoin.exe a computer joins an Active Directory domain without contacting a domain controller during the join: djoin /provision on a domain member creates the computer account and a base64 blob (with /machineOU for the target organisational unit), and djoin /requestODJ on the new machine applies it. (KB-2BU4, V1 docs, checked 2026-11-12)
- On a TCP Windows public image a scheduled task of type once that a #ps1_sysnative user_data creates for a few minutes later never runs: Cloudbase-Init runs its LocalScripts after the user_data, and 20-set-TimeZone moves the time zone from UTC to Central European time, so the start time lies an hour in the past. A task at system start or a detached Start-Process works. (KB-2ICQ, V3 live, checked 2026-11-18)
- A restored Windows server answered RDP after 235 seconds on Server 2019 and 269 seconds on Server 2022 at first boot. A cold rebuild of the same shape took 152 seconds. (KB-2IE5, V3 live, checked 2026-09-02)
- A Windows Server 2022 g7v ECS in eu-de created with key_name of the user's own RSA key and no adminPass accepted RDP with NLA as Administrator using the password read in the console with Get Password and the private key saved as a .pem file; no password change was demanded. (KB-2ODE, V3 live, checked 2026-11-10)
- A Windows Server 2019 ECS on s7n.large.4 in eu-de (public image Enterprise_Windows-Server_2019_STD_amd64_bios_latest) shows no VM Generation ID device, and a domain controller promoted on it has no msDS-GenerationId. A copy of that DC made from a private image kept the same invocation id, so the AD virtualization safeguards do not act on TCP. (KB-3Q3A, V3 live, checked 2026-11-18)
- The attack surface reduction rule that blocks credential stealing from LSASS is documented as an equivalent of RunAsPPL LSA Protection rather than a layer added on top of it. (KB-4LLB, V1 docs, checked 2026-06-11)
- Microsoft: FSLogix containers need a storage provider that supports SMB and works with the built-in Windows SMB client (Azure page blobs only with Cloud Cache). FSLogix may be used in any data center or cloud when the user holds an eligible licence, among them an RDS CAL or Microsoft 365 E3/E5/Business. The sizing example is 10 IOPS per user in steady state and 50 IOPS at sign-in and sign-out. On TCP this means a Windows SMB file server on ECS, since SFS has no SMB (KB-7TPW). (KB-4MLV, V1 docs, checked 2026-11-12)
- The Windows Server 2022 _prev public image on a g7v ECS reported Remaining Windows rearm count 1000 and License Status Licensed in slmgr /dlv, so Sysprep for a private image is not blocked by the rearm limit the IMS guide warns about. (KB-4T4V, V3 live, checked 2026-11-12)
- Software can be installed on a Windows ECS from an ISO held in OBS: the ISO is pulled into the guest with rclone, mounted with the PowerShell cmdlet Mount-DiskImage -PassThru, installed from the mounted drive letter and released with Dismount-DiskImage. (KB-4VOL, V3 live, checked 2026-06-17)
- LiDAR360 from GreenValley uses a node-locked license key with online activation through its License Manager. The key binds to the machine, and moving it requires a return or deactivation on the old machine before activation on the new one. (KB-7DW6, V3 live, checked 2026-06-17)
- netsh interface ipv4 show config on a German Windows Server 2019 prints the DHCP line as 'DHCP aktiviert: Nein' for a static NIC and for Loopback Pseudo-Interface 1. (KB-BTN6, V3 live, checked 2026-11-20)
- Microsoft: Entra join of Windows Server is listed only for Windows Server 2019 and newer virtual machines running in Azure, so a Windows Server ECS on TCP cannot be Entra joined; it can be Entra hybrid joined through a join to the on-premises Active Directory domain. Hybrid joined devices need periodic line of sight to a domain controller. The supported device list of the hybrid join pages names Windows Server 2016, 2019 and 2022 and did not name Windows Server 2025 on 2026-11-12. (KB-CEF2, V1 docs, checked 2026-11-12)
- Over SMB from a Windows file server ECS to another ECS in the same subnet (both s7n.xlarge.2, SSD system disks), listing a tree of 20,000 files of 1 to 8 KB took 0.8 s and copying it with robocopy /MT:16 took about 15 s. (KB-D3EU, V3 live, checked 2026-11-12)
- Microsoft: Windows 10 and Windows 11 Enterprise multi-session may not be run in production outside the Azure Virtual Desktop service. Multi-session desktops on TCP therefore run on Windows Server with the Remote Desktop Session Host role. (KB-D5J7, V1 docs, checked 2026-11-12)
- On Windows Server 2025 an ECS that is reachable only over RDP cannot complete a forced first-logon password change. The server requires NLA by default and the client stops with error 0x1207, password must be changed before logging on. (KB-EDZM, V3 live, checked 2026-06-11)
- A restored Windows server brings its data disk up Offline because of the SAN policy OfflineShared. Setting san policy=OnlineAll before the full-ECS image is created fixes this once in the image instead of at each restore. (KB-F535, V1 docs, checked 2026-09-02)
- Windows Server 2022 public images on TCP activate against kms.eu-de.otc-service.com:1688 from a server without EIP or NAT gateway: SoftwareLicensingProduct showed LicenseStatus 1 about 7 minutes after create. (KB-H27T, V3 live, checked 2026-11-12)
- FSLogix profile containers work on TCP with an SMB share on a Windows Server ECS: a domain user logged on to one session host got a VHDX on the share (164 MB), and a registry setting written there was present at the next logon on a second host; NTFS rights by AD group let the user write only to its group's project folder. (KB-IGMP, V3 live, checked 2026-11-12)
- Microsoft: every user or device that connects to a Windows Server Remote Desktop Session Host needs an RDS CAL. A licensing grace period of 120 days needs no licence server. Per-user CALs cannot be tracked in a workgroup, so a workgroup session host uses per-device CALs. A Windows Server 2025 session host takes only Windows Server 2025 RDS CALs; a Windows Server 2022 session host takes 2022 or 2025 CALs. (KB-IN2Y, V1 docs, checked 2026-11-12)
