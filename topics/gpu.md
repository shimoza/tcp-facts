# TCP Facts 2026-10-12: gpu

- On 2026-09-25 the eu-de public image catalog held 57 images flagged for GPU flavors, 45 of them Linux, and only six Linux ones name an NVIDIA driver in their description: Standard_Ubuntu_22.04_GPU_NV, latest and prev, with Nvidia public driver included, and Standard_RockyLinux_9_GRID in bios and uefi variants with the GRID driver file NVIDIA-Linux-x86_64-535.288.01-grid.run included. (KB-3JIJ, live, checked 2026-09-25)
- A 700B-class open MoE model in AWQ-INT4, served with the vllm/vllm-openai container on p5e.40xlarge.12 with eight H100 NVL cards, reached about 36 tokens per second with 0.11 s time to first token end to end. (KB-3QWJ, live, checked 2026-05-08)
- DJI Terra ships no official CLI or headless API. The backend engines DJIMapGen.exe, TerraWorkingProcess.exe, terra_3dgs.exe and DJIPicMapGen.exe are driven from an Electron GUI (DJIBrowser.exe). (KB-4A7E, docs, checked 2026-06-23)
- The NVIDIA Container Toolkit install guide requires an installed NVIDIA GPU driver and a supported container engine such as Docker, then the toolkit packages, and for Docker the command nvidia-ctk runtime configure --runtime=docker, which updates /etc/docker/daemon.json so that Docker can use the NVIDIA Container Runtime, followed by a restart of the Docker daemon. (KB-4C3N, docs, checked 2026-09-25)
- On an eight-GPU instance, docker rm -f followed immediately by docker run --gpus all sometimes gives the new container only seven GPUs while nvidia-smi -L on the host still lists eight, and torch aborts with device >= 0 && device < num_gpus. Restarting the docker daemon between swaps restored all eight. (KB-5GI3, live, checked 2026-05-07)
- vLLM 0.19.1 loading AWQ-INT4 weights through the compressed-tensors MarlinLinearKernel path repacks the layout in memory at load, about 110 seconds per 5 GB shard, single threaded per worker on cold page cache (81 shards, about 2.5 hours). Raising OMP_NUM_THREADS slowed it to about 200 seconds per shard on 80 vCPU. (KB-65QI, live, checked 2026-05-07)
- GPU flavors in eu-de come with fixed RAM, and every Windows GPU flavor cheaper than g6.10xlarge.7 on pay-as-you-go has 32 to 128 GB RAM (2026-09-25). g6.10xlarge.7 itself pairs one T4 with 280 GB RAM, and p2s.8xlarge.8 and p2v.8xlarge.8 reach 256 GB with only 32 vCPU. (KB-CQ2S, live, checked 2026-09-25)
- The p5s GPU flavors carry H100 PCIe cards, not H100 NVL, so their GPU topology differs from p5e. (KB-CSNR, live, checked 2026-09-25)
- The p5e.40xlarge.12 flavor (8x H100 NVL, 94 GB each) links its GPUs as NVLink bridge pairs without an NVSwitch fabric, so traffic between pairs goes over PCIe. nvidia-fabricmanager installs but fails to start there with 'Detected Pre-NVL5 system', leaving a broken systemd unit, so leave it out. (KB-DPSI, live, checked 2026-05-07)
- The flavor g6.10xlarge.7 in eu-de provides one T4 with 16 GB (about 15 GB usable framebuffer), 40 vCPU from 20 physical Xeon Gold 6266 cores at 3.0 GHz with hyper-threading, 280 GB RAM and dedicated CPU. (KB-F3C3, live, checked 2026-06-23)
- No H100 GPU flavor is available in eu-nl. On 2026-09-25 the ECS flavor list of eu-nl held no p5s or p5e flavor and no flavor with an H100 GPU, while eu-de listed four p5s and three p5e flavors, all in eu-de-01. (KB-IWD5, live, checked 2026-09-25)
- The p5s flavor carries H100 PCIe cards, a different GPU topology from the p5e H100 NVL flavors. (KB-JLBD, live, checked 2026-09-25)
- p5e.40xlarge.12 provides eight H100 NVL cards of 94 GB, wired as NVLink bridge pairs with no NVSwitch fabric, so cross-pair traffic falls back to PCIe. nvidia-fabricmanager installs but its unit fails to start and leaves a broken systemd unit behind. (KB-JRCC, live, checked 2026-05-07)
- Reserved terms of 12, 24 and 36 months are offered for the GPU flavor p5e.10xlarge.12 in eu-de, each also as an upfront-payment variant. (KB-KWII, contract, checked 2026-09-25)
- GPU flavors, pi5e included, keep billing compute while the instance is stopped. The pricing-models documentation is the billing-authoritative source; per-family spec notes stating the opposite are unreliable. (KB-MBIY, docs, checked 2026-07-02)
- In eu-de on 2026-09-25, p2s.16xlarge.8 (eight V100 of 32 GB, 64 vCPU, 512 GB RAM, end announced for 31.12.2026) and pi5e.24xlarge.4 (six L4 of 24 GB, 96 vCPU, 384 GB RAM) are orderable and take Windows Server images, so g7.12xlarge.8 (one A40 of 48 GB) is not the largest Windows-capable GPU flavor. g6.20xlarge.7 still offers two T4, 80 vCPU and 560 GB RAM. (KB-NIV7, live, checked 2026-09-25)
- DJI Terra is documented as compatible with NVIDIA graphics cards only, with a minimum of 4 GB VRAM and 32 GB RAM and a recommendation of an RTX 2070 with 64 GB RAM. (KB-QATO, docs, checked 2026-06-17)
- Section 3.1.1.2 of the TCP service description (revision 17.08.2026) marks the H100 flavor families p5s (NVIDIA H100) and p5e (NVIDIA H100 NVL) as only in EU-DE, and section 6.2.1.13 shows n.a. in every EU-NL column of all p5s and p5e rows. (KB-QLMG, contract, checked 2026-09-25)
- A DJI Terra LiDAR reconstruction on g6.10xlarge.7 peaked at about 127 GB working set (about 135 GB including the OS) and about 3 GB of the 15 GB framebuffer, with GPU utilisation mostly low. The RAM peak is dataset-bound and stayed the same at 1, 3 and 4 computing cores. (KB-TVQH, live, checked 2026-06-23)
- On 2026-09-25 in eu-de-01 only p5s.20xlarge.12 showed the status normal, while p5s.5xlarge.12, p5s.10xlarge.12, p5s.40xlarge.12 and all three p5e flavors showed sellout. (KB-USSN, live, checked 2026-09-25)
