# TCP Facts 2026-10-14: pricing

- The price API returns rows for flavors marked sellout in cond:operation:az and for ramped-down services. Orderability follows from the per-AZ state, not from the presence of a price row. (KB-4ABK, live, checked 2026-09-25)
- No public service description of the Swiss offering (eu-ch2) was found on 2026-10-08: the TCP service description revision 17.08.2026 covers EU-DE and EU-NL only, the Swiss product pages link that same general document, and the operator's Swiss site offers a price calculator in CHF and a technical flyer of 2022 but no service description or price list. What is offered in eu-ch2 has to be confirmed with the Swiss entity before it is quoted. (KB-4FW6, docs, checked 2026-10-08)
- Answers of the public price API can carry response.cachedAt, the time of a server cache in server time, two hours ahead of UTC on 2026-09-24. That day an unfiltered query answered from a cache of 2026-09-07 and a query for sn=ecs from one of 2026-09-17, so a price read today can come from a cache more than two weeks old. (KB-5LLN, live, checked 2026-09-24)
- A price API result for one sn can contain records of another product: the sn=dc result for rn=eu-de carried one stray DAS row, distinguishable by its productName field. (KB-6A7H, live, checked 2026-08-25)
- In the c9 price table of the TCP service description the flavour name is printed on the Oracle row, and the open Linux row directly above it carries its rate without a flavour name. A search combining a c9 flavour name with the words open Linux matches nothing. (KB-6HHT, contract, checked 2026-09-11)
- The TCP price API returns rows for services that are no longer offerable. By 2026-09-02 this had been observed for SFS Common I/O, BMS and DIS, so a price-API hit alone does not show that a service can be ordered. (KB-7VPP, live, checked 2026-09-24)
- Every record of the public price API has an id, a SKU code, while opiFlavour is empty on some: in eu-de on 2026-09-24 on 11 of 461 rds records, 1 of 11 eip records and 6 of 27 coss records. Every ecs, deh, obs, elb and nat record carried one. The id is the key to look a record up by. (KB-AEVL, live, checked 2026-09-24)
- In the TCP service description the commercial limit per business partner (section 3.1.1.1, footnote 2) and the footnote 1 marker for no guaranteed capacity are set only on the flexible-purpose families x1, x1e, x1m, x2, x2e, x2m and x2ne. The s9, m9 and c9 rows carry neither marker. (KB-AH5P, contract, checked 2026-09-11)
- The price API covers the s2, s3, s7n and s9 ECS families, so a flavor missing from the price API can still be listed in the service description catalog. (KB-AI2E, live, checked 2026-07-15)
- A query of the price API that matches nothing answers HTTP 200 with stats.count 0 and result as an empty list, while a query that matches answers result as an object keyed by service name. A service name the API does not know answers HTTP 500 with code Error, so an empty answer and a refused query can be told apart. (KB-BVUH, live, checked 2026-09-24)
- A price change is pre-announced inside the current revision of the service description. A section 6 price row can carry a "from DD.MM.YYYY:" subline: the value under the marker is the new hourly price, the value on the row above is the one in force until that date. (KB-FBVR, contract, checked 2026-07-05)
- Money values returned by the public price API use English number formatting: comma as thousands separator, dot as decimal separator, six decimal places, and the currency code appended after the value. (KB-FE6O, live, checked 2026-06-11)
- Windows ECS are priced in a separate, higher tier per flavor than the Open Linux tier: on 2026-09-24 the Windows rate was higher on all 306 flavors of the six ECS service names in eu-de that carry both. The OS of every VM decides which price row applies. (KB-FIBF, live, checked 2026-09-24)
- Price rows in the service description can carry a "from <date>:" subline that announces a future value, so a parser reading only the main row returns the superseded value. (KB-FZRN, contract, checked 2026-07-01)
- The en variant of the price API writes every amount as a number with a decimal point, a comma as thousands separator and the currency code after it, while the de variant writes a decimal comma. A reader has to know which variant it reads, because a comma followed by three digits is ambiguous on its own. (KB-H5VQ, live, checked 2026-09-24)
- A pre-announced price change can move different rows by different ratios. In the change effective 01.07.2026, 81 of 90 affected ECS price points moved by factor 1.2500 and the nine s9 Windows rows by 1.1103, the compute and the Windows license component moving separately. (KB-HOSK, contract, checked 2026-07-05)
- A query to the TCP price API with sn=ucs returned HTTP 500 rather than an empty result set. (KB-HSN2, live, checked 2026-09-01)
- Reserved terms and discount depth are family-dependent: the 36-month term is offered for part of the ECS families. (KB-HSTO, live, checked 2026-09-25)
- The unit field of the price API is free text with about 20 values, among them h, GB/month, Item/month, h/month and an empty unit. isMRC is true on some records whose unit is h, so neither field alone tells an hourly rate from a monthly one. (KB-HYBW, live, checked 2026-09-24)
- The service description lists flavor x1e.slarge.2 with 3 vCPU and 6 GB RAM, a specification the flavor name does not reflect. (KB-IDKJ, contract, checked 2026-07-01)
- The Financial Dashboard has a consumption view by tag with hourly and daily granularity and key/value selection, backed by the Business.tag_daily and Business.tag_hourly tables. Tagged resource costs appear in the invoice CSV. The invoice document stays per tenant and not every product is taggable. (KB-JDBN, docs, checked 2026-07-17)
- The public price API returns money values in English number format: a comma separates thousands and a dot separates decimals, followed by the currency code. A parser that reads the comma as a decimal separator returns values a thousand times too low. (KB-NCPE, live, checked 2026-06-11)
- The price API switches to the announced value on the effective date. For the flavor families the API covers, the from-column of the service description and the API value agree to six decimals. (KB-PL7K, live, checked 2026-07-05)
- The eu-ch2 slice of the public TCP price API is not the Swiss price list: on 2026-10-08 it held 75 records marked EUR, 15 of them (KMS API calls, the five OBS Standard Space tiers, eight SMN rows) with exactly the numbers the Swiss calculator shows as CHF, and 60 rows that the Swiss calculator does not carry at all (API Gateway, HSS, WAF domain, FunctionGraph, LTS, DNS queries, OBS cold and warm space, outbound traffic, a firewall and VPN row), most of them priced zero. It carries no ECS, EVS or RDS row for eu-ch2, and its values were unchanged between 2026-09-24 and 2026-10-08. (KB-PRGT, live, checked 2026-10-08)
- The service description lists UCS rates in section 6.8.5, billed per hour and per CPU in the cluster, with the same rate for clusters inside and outside the tenant and the eu-nl region marked as not applicable. (KB-QIV4, contract, checked 2026-09-01)
- Prices of the Swiss offering (region eu-ch2) come from a price calculator of its own on the operator's Swiss site (calculator client 2), in CHF: on 2026-10-08 it had 19 modules with 255 records, among them 146 ECS rows (s3 flavors; Open Linux, Oracle Linux, RedHat, SUSE, SUSE for SAP and Windows tiers), 40 RDS rows, Direct Connect, Dedicated Host, CCE, EVS (SAS and SSD), OBS, EIP, ELB, NAT, private DNS, VPC, VPC endpoint, KMS, SMN, CBR, SDRS, AOM and dedicated WAF, with pay-as-you-use and 12-month reserved packages. The main TCP calculator lists eu-ch2 in its region picker but its module picker returns no module for that region. (KB-QWED, live, checked 2026-10-08)
- In the price API, sn=ecs covers only the s2, s3, s7n and s9 families. The vss.* entries in that payload are EVS disk SKUs rather than a compute family, and the other ECS families sit under other service names of the price API. (KB-RMW2, live, checked 2026-09-24)
- The price API returns rows and the documentation mirror keeps full user guides and API references for services that are no longer offered, VBS and CSBS (end of life since 01.01.2026) among them, so presence in either source does not show that a service is orderable. For BMS in eu-de on 2026-09-25, the legacy BMS flavors are all abandon or sellout, while the bms rows of the price API now cover the orderable Physical ECS flavor c7t.28xl. (KB-SCLG, live, checked 2026-09-25)
- In the public price API the service name sn=dcaas returns HTTP 500, while sn=dc with rn=eu-de returns the full Direct Connect price list including bandwidth tiers and ports. The same service can be served under an abbreviation different from the one used elsewhere. (KB-SEDA, live, checked 2026-08-25)
- The public price API returns a changing set of ECS records: 502, then 508, then 400 within one month, with the x1 family and the s3 R36 reserved fields disappearing between calls. (KB-SFUF, live, checked 2026-07-01)
- Reserved price rows can be left out of a pre-announced increase. In the change effective 01.07.2026 the R12, R24 and R36 cells carried no from-date marker and their values did not move. (KB-SUE5, contract, checked 2026-07-05)
- The public TCP price API answers at https://calculator.otc-service.com/en/open-telekom-price-api/ with JSON and needs no key. It takes sn for the service name and rn for the region. limitFrom pages through the records and limitMax sets how many come per page: 500 without it, while limitMax=10000 returned each region in one answer on 2026-09-24. (KB-W7ZS, live, checked 2026-09-24)
- The public price API held these record counts on 2026-09-24: eu-de 3386 records under 100 service names, eu-nl 2638 records under 64 names and eu-ch2 75 records under 14 names. (KB-XEGQ, live, checked 2026-09-24)
- A record in the public price API does not show that a service can still be ordered: rows stay served for services that have reached end of life, so orderability has to be confirmed against the service catalog. (KB-XELM, live, checked 2026-09-24)
- Record ids of the price API are specific to a region: on 2026-09-24 none of the 6099 ids of eu-de, eu-nl and eu-ch2 appeared in two regions, so an id also fixes the region. (KB-XJDA, live, checked 2026-09-24)
- SKU ids seen in the price API for network and object items include OTC_OBST_SP_2 (OBS Standard storage), OTC_OBST_REQ (OBS requests per 1000), OTC_LBV3_B_2AZ_20 (dedicated ELB, 2 AZ, 20 LCU), OTC_ELASTIC_IP and OTC_VPC_UP_S_2 (egress tier). (KB-YAT6, live, checked 2026-09-24)
- In eu-de on 2026-09-24 the price API held the x1 family under sn=ecsflex in the size ratios 2, 3 and 4 only, 18 flavors, and held no m3 flavor under any of the six ECS service names. (KB-YUVN, live, checked 2026-09-24)
- A reservation is bound to the instance type it was bought for and does not follow a downsize of the instance. (KB-ZJ4B, contract, checked 2026-07-01)
- Records of the price API with idGroupTiered set carry the bounds of their tier in fromOn and upTo. On 2026-09-24 there were 355 such records in 18 groups in eu-de and eu-nl, most of them outbound internet traffic (group OTC_VPC_UP) and OBS outbound traffic. (KB-ZNJK, live, checked 2026-09-24)
