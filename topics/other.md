# TCP Facts 2026-10-28: other

- HetuEngine in MRS 3.5.0-LTS does not support registering an Iceberg catalog as shipped, because HSConsole has no ICEBERG data source type. Workaround: repoint the template of an unused type in HSConsole etc/datasource.properties, restart HetuEngine, then POST the catalog to /v1/hsconsole/datasource on port 29880. (KB-2KDP, live, checked 2026-07-28)
- The base service description, revision 09.10.2026, section 4.2, names a single availability figure: a monthly platform availability target of 99.95%, which applies separately to Elastic Cloud Server, Object Storage Service and Elastic Volume Service. For all other services it states that there is no minimum availability. (KB-35HK, contract, checked 2026-10-14)
- FunctionGraph scales to zero when idle and idle time is not charged. (KB-3FHX, docs, checked 2026-08-27)
- FunctionGraph is a managed serverless service that hosts and runs event-driven functions: the customer writes code and sets the trigger conditions, and the service manages the compute resources and scales automatically with the number of requests. Functions are written in Node.js, Python, Java, C#, PHP, Go or a custom runtime and are triggered by API calls or cloud service events; reserved instances keep functions warm against cold starts. The Regions and Endpoints page lists the FunctionGraph API endpoint in eu-de. (KB-3L75, contract, checked 2026-10-14)
- Managed Services are optional operations services that Telekom provides on T Cloud Public (TCP) in three packages, Managed Services Basic, Standard and Advanced, covering up to 20, 50 or 150 managed services (operating systems, databases and applications). The portfolio catalogue names applications (Nginx, Tomcat, Apache, firewall, VPN, GitLab), RDS for SQL Server, MySQL and PostgreSQL and self-run SQL Server, MySQL, Oracle, MariaDB and PostgreSQL, managed Linux and Windows Server operating systems and managed containers; larger or custom scopes are offered individually. (KB-4N6Q, contract, checked 2026-10-14)
- MRS Spark defaults to spark.sql.storeAssignmentPolicy=LEGACY, which DataSource V2 rejects with 'LEGACY store assignment policy is disallowed in Spark data source V2'. Set --conf spark.sql.storeAssignmentPolicy=ANSI for any Iceberg INSERT. (KB-4Y2C, live, checked 2026-07-28)
- DORA Article 28(8) requires financial entities to put in place exit strategies for ICT services supporting critical or important functions, with comprehensive and documented exit plans that are tested and reviewed periodically, and with transition plans to move the services and data to another provider or back in-house. (KB-6YSY, docs, checked 2026-09-25)
- A word-boundary search for nifi across the documentation mirror returned zero hits, so no managed Apache NiFi service is documented. (KB-7KEU, docs, checked 2026-10-14)
- Enterprise Agreement 1.0 (EA10) is an optional extended service contract from Telekom in the service classes Silver, Gold and Platinum, ordered separately on top of the standard service. All classes add a consulting and administration service; Gold and Platinum add IT architecture consulting, an availability report and service meetings; Platinum adds dedicated service and delivery management and a manager on duty service. Service levels, response times and credits are contract terms and are not stated here. (KB-7U4I, contract, checked 2026-10-14)
- Data Admin Service (DAS) is a cloud database management platform in preview for managing databases on a web console, with database development, operations and intelligent diagnosis. The service description of 09.10.2026 announces it as expected to be available from 1 May 2027, and as a preview version it is meant for testing. (KB-AB67, contract, checked 2026-10-14)
- Secure Mail Gateway (SMG) lets applications hosted on T Cloud Public (TCP) send email to the internet through a gateway service, so the sending servers' own IP addresses do not land on spam blacklists; outbound SMTP on ports 465 and 587 is opened only towards this gateway. The documentation names anti-virus and anti-spam checks, three mail servers spread over eu-de-01, eu-de-02 and eu-de-03, and a possible limit of 100 mails per minute per customer, which the service description also reserves. (KB-BGAJ, contract, checked 2026-10-14)
- Consulting Services (CS) are optional consulting services from Telekom in the T Cloud Public (TCP) environment, commissioned separately through the T Cloud Public Support Center, that go beyond the support services of the standard contract. (KB-CXIW, contract, checked 2026-10-14)
- The public platform is branded T Cloud Public (TCP) after the 2025 rename. The service description carries the title "Service Specifications & Additional Terms and Conditions T Cloud Public". (KB-DFXG, contract, checked 2026-07-15)
- On the shared default DLI queue, statements stayed in LAUNCHING for over 15 minutes and the synchronous submit returned DLI.0019 Get sync job result timeout; the job id is in the error text. Capability tests need a dedicated queue or elastic resource pool. (KB-ETTV, live, checked 2026-07-28)
- Section 7.3 of the TCP service description, revision of 2026-10-09, freezes a tenant for the two weeks before its termination takes effect and erases all its resources when it does, and section 7.5 requires the customer to back up its application data on its own responsibility before that grace period. (KB-F3A4, contract, checked 2026-10-14)
- In a HetuEngine Iceberg data source on MRS, hive.config.resources needs absolute paths; relative paths make reads fail with 'EndPoint is not set'. (KB-FAPL, live, checked 2026-07-28)

A product offering combines the service type, which is Cloud Container Engine, the license type (open source, free or trial, bring your own license, or private offer) and the seller's software. (KB-FFRB, contract, checked 2026-10-14)

- Tag Management Service (TMS) adds key-value tags as metadata to cloud resources and manages them centrally across services and regions; tags are created by hand or predefined and imported in CSV format, and resources are searched and filtered by tag. Costs can be assigned to tags in the invoice documents and in the Financial Dashboard. The Regions and Endpoints page lists API endpoints for TMS in eu-de and eu-nl. (KB-HFN2, contract, checked 2026-10-14)
- DORA Article 30(3)(f) makes exit strategies a mandatory term of contracts for ICT services supporting critical or important functions, in particular an adequate transition period in which the ICT third-party service provider keeps providing the service while the financial entity moves to another provider or in-house. Article 30(2)(d) requires every ICT services contract to provide for access, recovery and return of the data on termination or on the provider's insolvency, resolution or end of business. (KB-K5U4, docs, checked 2026-09-25)
- In MRS 3.5.0-LTS, impalad runs on the core nodes and listens on ports 21050 and 21000, so Impala clients connect to a core node. (KB-K6OT, live, checked 2026-07-28)
- Config (Resource Management Service, RMS) lets the customer centrally view all resources of a tenant with their details and relationships. The documentation adds a resource recorder that keeps change records and snapshots in an OBS bucket and sends change notifications through Simple Message Notification, compliance evaluation of resources against Config rules, and advanced queries in ResourceQL. The Regions and Endpoints page lists API endpoints for Config in eu-de and eu-nl. (KB-KHDV, contract, checked 2026-10-14)
- Section 7.2.3 of the TCP service description, revision of 2026-10-09, gives a customer who notifies a migration under the Data Act at least 30 days ahead a 30-day transition period. The customer may extend it once, and it never exceeds seven months. (KB-KT7I, contract, checked 2026-10-14)

- Data Replication Service (DRS) migrates and synchronizes databases online in real time, to simplify data migration and reduce migration effort; the customer gets tools to query the migration progress, check migration logs and compare migrated items. The Regions and Endpoints page lists API endpoints for DRS in eu-de and eu-nl. (KB-LSZV, contract, checked 2026-10-14)

Request throttling, authentication, environments with environment variables, signatures, version rollback and API monitoring with alarms are configured per API. The Regions and Endpoints page lists the APIG API endpoint in eu-de. (KB-MIJ4, contract, checked 2026-10-14)

- DORA Article 2(2) calls only the entities of points (a) to (t) of Article 2(1) financial entities, so ICT third-party service providers, listed separately under point (u), are not the addressees of the exit duty in Article 28, and Article 28(1)(a) keeps financial entities fully responsible for compliance when they use ICT services. (KB-NLXT, docs, checked 2026-09-25)

The user needs a Manager role with Submit and Admin on YARN queue root.default (without it hetu-cli reports 'user does not belong to the specified tenant') and membership in the hetuuser group, which takes effect only after a HetuEngine restart. (KB-NVXS, live, checked 2026-07-28)

Service levels, response times and credits are contract terms and are not stated here. (KB-NZSQ, contract, checked 2026-10-14)

It is used through open APIs, and the documentation describes general OCR that extracts text from images of tables, documents, receipts and forms and returns it in JSON format. The Regions and Endpoints page lists the OCR API endpoint in eu-de. (KB-OBHQ, contract, checked 2026-10-14)
- Financial Dashboard (FD, former Enterprise Dashboard) gives the customer an overview of the resources used and their costs in a separate portal reached through MyWorkplace, with predefined and custom diagrams, CSV and API export, and email notification when customer-set cost thresholds are reached. It comes as Small, which is included in the standard scope, Medium and Large; Medium and Large add support for several T Cloud Public tenants and Large adds organization management. (KB-QAFU, contract, checked 2026-10-14)
- The DORA oversight framework of Chapter V Section II applies to ICT third-party service providers that the ESAs designate as critical under Article 31(1)(a), and under Article 31(9) the ESAs publish and update the list of critical providers yearly. (KB-QILM, docs, checked 2026-09-25)

(KB-U7RP, contract, checked 2026-10-14)

The documentation describes out-of-path audit of RDS databases and of databases the customer runs on Elastic Cloud Servers, among them TaurusDB, MySQL, PostgreSQL and SQL Server. DBSS is offered in eu-de (KB-22YR, KB-JM53). (KB-UUZF, contract, checked 2026-10-14)

The Regions and Endpoints page lists the DDM API endpoint in eu-de. (KB-WVTD, contract, checked 2026-10-14)
