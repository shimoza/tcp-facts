# TCP Facts 2026-10-28: security

- Section 6.10.6 of the TCP service description (revision 09.10.2026) lists DBSS Basic, Pro and Advanced for EU-DE only (n.a. for EU-NL), while section 6.10.5 (dedicated WAF Professional and Enterprise), section 6.10.7 (HSS Enterprise, Premium, WTP and Container editions) and section 6.10.9 (Cloud Firewall) list both EU-DE and EU-NL. (KB-22YR, contract, checked 2026-10-14)
- Under the ErgB-AV for T Cloud Public of April 2026 the contracting company acts as subprocessor when a customer processes personal data on behalf of its own customers, with the approved subprocessors of the platform listed in Appendix IV. GDPR Article 28(2) lets such a customer engage another processor only with the prior specific or general written authorisation of its controllers and, under a general authorisation, requires it to inform them of any intended addition or replacement of other processors. (KB-3EX6, contract, checked 2026-09-25)
- GET /v1/resource-manager/policy-definitions returned 87 built-in policy definitions for eu-de on that date, among them required-tag-check, required-all-tags, required-tag-exist, resource-tag-not-empty, ecs-instance-no-public-ip, elb-loadbalancers-no-public-ip, rds-instance-no-public-ip and eip-unbound-check. (KB-5TJI, live, checked 2026-09-25, recheck due)
- A Config/RMS run-evaluation call is accepted with HTTP 202 and the per-resource Compliant or NonCompliant results appear in policy-states about one to two minutes later, covering every project in the domain. (KB-6MGX, live, checked 2026-07-17)
- A Config policy assignment is written with PUT /v1/resource-manager/domains/{domain_id}/policy-assignments and requires the resource recorder to be enabled, otherwise the call returns 400 RMS.00010091. POST on the assignment's policy-states/run-evaluation returns HTTP 202 and per-resource Compliant or NonCompliant states appear after one to two minutes. (KB-AXSS, live, checked 2026-07-17)
- The built-in Config/RMS policy resource-tag-not-empty takes no parameters, while required-tag-check requires both a tag key and a tag value. An assignment is scoped by provider, resource type and region. (KB-FVUY, live, checked 2026-07-17)
- BSI C5:2020 Type 2 attestation is held for the platform and re-attested at least every 12 months. (KB-GEDK, docs, checked 2026-09-25, recheck due)
- Cloud Secret Management Service (CSMS) has no reachable API endpoint in eu-de: GET /v1/{project_id}/secrets on the KMS host answers HTTP 404 APIGW.0101 and no csms host name resolves. Ask the operator how to reach CSMS in eu-de. (KB-GUHJ, live, checked 2026-09-25)
- Config/RMS in eu-de provides 87 built-in policies, among them required-tag and no-public-ip rules. A resource recorder plus a policy assignment returns per-resource compliance verdicts. (KB-HGAP, docs, checked 2026-09-25, recheck due)
- DBSS is not offered in eu-nl. On 2026-09-25 the DBSS audit API answered 404 APIGW.0101 in eu-nl but reached the service in eu-de (403 for a user without DBSS rights), and the public price API had DBSS records only for eu-de. (KB-JM53, live, checked 2026-09-25, recheck due)
- BSI IT-Grundschutz certification is still in progress on 2026-09-25: filed 2025-07-28, on the BSI list of ongoing procedures as BSI-IGZ-0757, audit phase planned from January 2026, certificate expected in Q4 2026. The listing is a pending procedure, not a certificate, and the BSI list says nothing about tenders. (KB-NZRC, docs, checked 2026-09-25, recheck due)
- A DNS probe on 2026-07-02 found that the SCM and CCM service endpoint names for eu-de do not resolve, so no managed certificate service endpoint answered in eu-de. (KB-OK4D, live, checked 2026-09-25, recheck due)
- HSS ransomware prevention (Premium, WTP and Container editions) is host-agent detection and response with honeypot files and an optional server backup to a CBR vault, so HSS itself gives detection, not immutability; write-once (WORM) backups come from the separate CBR vault setting backup locking, which covers only automatic backups. On Windows the Premium and WTP editions add a self-protection policy, active when at least two of antivirus, HIPS and ransomware protection are on, that stops HSS processes from being ended and the agent from being uninstalled on the server; the docs list it for Windows only (checked 2026-09-25). (KB-QWTI, docs, checked 2026-09-25)
- In the T Cloud Public (TCP) contractual service description the product name Anti-DDoS is written with the Unicode hyphen U+2010 instead of the ASCII hyphen-minus. A text search of the extracted document text for the ASCII spelling returns zero hits. (KB-ZPJG, contract, checked 2026-09-08)
